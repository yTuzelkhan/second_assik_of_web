## Part 1 — Flexbox

### Task 0 — Navigation Bar

A navigation bar was created using CSS Flexbox. The logo is positioned on the left, while the navigation links are positioned on the right. `justify-content: space-between` and `align-items: center` are used for alignment and spacing.

### Task 1 — Card Row

Three cards were created using Flexbox. Each card contains an image, title, description, and button. The cards are displayed in a row with equal width and consistent spacing. A hover effect using `box-shadow` was also added.

## Part 2 — Grid System

### Task 2 — Page Layout with Grid Areas

A page layout was created using CSS Grid with four sections: header, sidebar, main content, and footer. `grid-template-areas` was used to organize the position of each section.

### Task 3 — Image Gallery

A nine-image gallery was created using CSS Grid. The gallery contains three equal-width columns with consistent gaps. A hover effect displays a caption overlay when the user moves the mouse over an image.
